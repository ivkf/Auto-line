# Auto Line Discord Bot

## Overview
Auto Line is a Discord bot designed to automatically send images in specific channels in response to messages. The bot allows you to configure image URLs and channels using simple slash commands.

## Setup
- Add your bot token in **line 4** of `bot.js`.
- Add your bot ID in **line 5** of `bot.js`.

## Features
- Automatically sends images to specified channels in response to messages.
- Supports adding and removing image configurations via slash commands.
